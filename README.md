# 시나리오 모드 그림 (외부 저장소에서 가져온 것)

시나리오 모드(개발자 빌드)의 배경·아이콘. GitHub Pages 배포 때 `scn/` 가 사이트의 `/scn/` 으로 복사되고, 앱은 주소로 불러 씀(없으면 앱에 들어 있는 직접 그린 그림으로 대신함).
**문제가 되면 이 브랜치를 지우면 됨** — 다음 배포부터 사이트에서 빠지고 앱은 직접 그린 그림으로 돌아감.

| 폴더 | 내용 | 출처 |
|---|---|---|
| `scn/bg/*.jpg` | 지역 배경 11장 | Pokémon Showdown 클라이언트의 배틀 배경 (`play.pokemonshowdown.com/fx/bg-*.png`, `/sprites/gen6bgs/*.jpg`) |
| `scn/ico/*.png` | 도구·배지 아이콘 | PokeAPI/sprites (`sprites/items`, `sprites/badges`) |

배경 짝: pallet=gen6 meadow · route=fx route · viridian=gen6 city · forest=gen6 forest · pewter=fx mountain · mtmoon=gen6 dampcave · cerulean=gen6 aquacordetown · bridge=fx river · cape=gen6 beach · pool=gen6 leaderwallace · lab=gen6 library

이 그림들의 저작권은 각 원저작자(Nintendo / Creatures / GAME FREAK 등)에게 있음. 팬 제작 용도로만 씀.
