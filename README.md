# 트레이너 초상화 (시나리오 모드 시안용, 임시)

저장소 주인이 AI 로 만든 상반신 그림 332장을 `battle-kr/scripts/make-portraits.py` 로 흰 배경을 지우고 416×608 WebP 로 줄인 것.
GitHub Pages 배포 때 `portraits/` 가 사이트의 `/portraits/` 로 복사되고, 시나리오 모드(개발자 빌드)가 `<id>.webp` 로 불러 쓴다. id = 영어 이름의 소문자·숫자만 (예: `professoroak`, `teamrocketgrunt`).
임시 그림이므로 바뀔 수 있다.
