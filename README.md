# 움직이는 도트 그림 묶음 (개발자 빌드 시험용)

배틀시뮬 KR 개발자 빌드(/dev/)의 「움직이는 도트 (시험)」 설정이 쓰는 그림. GitHub Pages 배포 때 `ani/` 가 사이트의 `/ani/` 로 복사된다.
main 브랜치의 `battle-kr/scripts/make-ani-sprites.py` 로 만든다 (프레임 띠 PNG → 움직이는 WebP, 앞 1,318 · 뒤 1,317).
