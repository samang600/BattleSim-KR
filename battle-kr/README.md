# 배틀 시뮬레이터 KR (한국어 포켓몬 배틀 시뮬레이터)

스마트폰에서 바로 하는 한국어 포켓몬 배틀 앱. 배틀 계산은 이 저장소의 **Pokémon Showdown 시뮬레이터(`sim/`)를 그대로** 브라우저에서 돌립니다.

## 받기
- **안드로이드**: [`release/BattleSimKR-v2.81.1.apk`](release/BattleSimKR-v2.81.1.apk) (약 2MB, 칩튠 배경음악 포함) 를 받아 설치 (출처를 알 수 없는 앱 허용 필요, 안드로이드 7.0 이상)
- 그림·울음소리·기술 애니메이션은 기본적으로 인터넷에서 그때그때 받습니다. **설정 → 오프라인 데이터 → 한 번에 받기**(약 24MB 내려받기, 풀면 약 60MB)를 누르면 앱 저장소에 받아 두어 인터넷 없이도 모두 나옵니다.
- **웹 (설치 없이)**: **https://samang600.github.io/BattleSim-KR/** — 아이폰·PC·안드로이드 브라우저에서 바로 실행 (홈 화면에 추가 → 앱처럼 실행). 웹은 `web` 브랜치를 빌드해 올립니다(`.github/workflows/pages.yml`, main 에 푸시하거나 수동 실행 때). 웹에 올릴 때는 `web` 브랜치를 main 으로 옮긴 뒤 워크플로를 다시 실행합니다(main 에 푸시해도 웹은 `web` 브랜치 그대로). 지금 웹은 v2.54.6.
  - 방문자 수는 GoatCounter(쿠키 없음)로 집계합니다: https://samang600.goatcounter.com — 웹 배포 주소에서만 세고 안드로이드 앱은 세지 않습니다.
  - 웹에서는 타이틀·메인 화면 오른쪽 위와 배틀 ☰ 메뉴에 **전체화면** 버튼이 있습니다(안드로이드 앱은 원래 전체화면이라 숨김, 아이폰 사파리는 브라우저가 지원하지 않아 숨김 — 홈 화면에 추가하면 주소창 없이 실행).
- **직접 올리기**: `dist/index.html` 한 파일(+아이콘·manifest·sw.js)을 어느 웹 서버에 올려도 됩니다
- **포켓몬 그림 바꾸기**(설정): 포켓몬마다 앞·뒤·색이 다른 모습 그림을 내 그림 파일로 바꿀 수 있습니다. 정지 도트 그림 설정에서는 내 그림이 먼저 나오고, 3D 그림 설정에서는 그림을 받을 수 없을 때(오프라인 등) 이름 카드 대신 나옵니다. 정수배로 키운 도트 그림은 원래 크기로, 큰 그림은 96×96 칸에 맞춰 넣습니다(`src/user-sprites.ts`, 저장은 IndexedDB — 그림이 많아도 됨, 데이터 백업에는 들어가지 않으니 '내 그림 내보내기' zip 으로 보관).
  - **원본 추출·일괄 적용**(v2.53.7, `src/sprite-pack.ts`·`src/zip.ts`): 한 포켓몬 원본(앞·뒤·색이 다른 모습) / 원본 전체(약 5400장, 오프라인 그림 묶음 + 앱에 넣은 그림)를 zip 으로 추출, 내 그림을 zip 으로 내보내기, zip 이나 그림 여러 장을 한 번에 적용, 모두 원래대로. zip 구조는 `gen5/`(앞)·`gen5-back/`·`gen5-shiny/`·`gen5-back-shiny/` 폴더 안 `<그림 id>.png` — 원본 전체를 추출해 고친 뒤 그대로 적용하면 됩니다. 폴더 없이 `pikachu-back-shiny.png` 같은 이름도 됩니다. 안드로이드 앱은 저장 위치를 고르는 창이 뜨고, 파일 고르기에서 여러 장 선택 가능. 페로코체 도트 그림은 사용자가 준 그림으로 교체.
- 9세대 포켓몬 139종의 정지 도트 뒷모습: 쇼다운 서버 그림이 앞모습을 좌우로 뒤집은 것이라, PokeAPI/sprites 의 진짜 뒷모습(DoveKyle, 색이 다른 모습 포함)을 앱에 넣어 씀(`scripts/fetch-gen9-backs.py`). 3D 그림 설정에서는 3D 뒷모습이 먼저.
- 쇼다운 서버에 도트 그림 대신 3D 그림을 줄인 임시 그림만 있는 9세대 16개(퍼퓨돈 암컷·빠모트·스태솔트·찌리비·육파리·구르데·베라카스·키키링·차데스(두 모습)·오거폰 벽록의가면·오거폰 테라스탈 4모습·무쇠감투)는 PokéAPI sprites 저장소의 도트 그림(앞모습 KingOfThe-X-Roads, 뒷모습 DoveKyle, 출처 표기)을 앱 안에 넣어 씁니다(`src/sprites-custom`, 색이 다른 모습 포함).
- 포켓몬 그림은 기본이 정지 도트 그림(오프라인 데이터를 받아 두면 인터넷 없이도)이고, 설정에서 '움직이는 그림'을 고르면 인터넷에서 3D 움직이는 그림을 받아 씁니다. 거다이맥스하면 거다이맥스 전용 그림.

- PC 넓은 화면의 배틀 필드에는 도트 베젤 프레임(휴대폰 가로는 얇은 선만)(진한 선·흰 선·금속 띠 3칸·외곽선, 모서리 나사·위 표시등, 색은 창틀 디자인을 따름).
- 배틀 필드는 세로·가로·PC 모두 16:9 — 배경 그림 위쪽 빈 하늘 띠를 잘라 HP 창이 배경(기둥·창) 위에 겹쳐 보입니다. 타이틀은 로고·포켓몬을 화면 위쪽에 둡니다.
- 테라스탈한 포켓몬은 그림 모양대로 반투명한 보석 결(삼각 면 무늬 + 테라 타입 색, SVG 필터)이 겹쳐 보입니다(바깥에 타입 색 빛이 은은하게 점멸, 2.4초마다 빛 띠가 대각선으로 훑고 지나가고 결정 면 위에 작은 별이 깜박임). 다이맥스는 빨간 바깥 빛이 은은하게 점멸. 빗나가거나 막힌(방어·무효·실패) 기술은 기술 연출을 생략하고, '급소에 맞았다!'는 노란 글자. 힘껏펀치·부리캐논·트랩셸은 턴 처음에 기운을 모으는 준비 연출(주황빛 모임 / 불티 아지랑이 / 육각 등껍질 고리), 솔라빔·공중날기 같은 2턴 기술은 준비 턴에 기술 타입 색으로 기운을 모으고 기술 연출은 실제로 쓸 때만. 테라 배지는 HP 숫자와 같은 줄.
- HP 창에는 상태이상·테라만 표시하고, 랭크 변화·혼란 등 기타 상태는 '필드' 메뉴(필드 상황)에서 포켓몬별로 봅니다. 스텔라 테라는 남색.
- 포켓몬 그림 크기 보정(`scripts/sprite-scale.py` → `src/gen/sprite-scale.json`): 메가진화·원시회귀가 기본 모습보다 작아 보이지 않게(칠해진 픽셀 수 기준 기본 모습의 1.3배 덩치) 키우고, 3D 그림 설정에서 3D 그림이 없어 도트 그림으로 나오는 포켓몬은 1.3배로 맞춤. 레전즈 Z-A 메가는 웹에서도 PokeAPI 도트 그림을 받아 씀.
- 휴대폰 가로 화면은 작은 화면(예: 600×270)에서도 오른쪽 칸이 깨지지 않게 얇은 테두리·화면 높이 비례 버튼, 칸이 좁으면 타입 글자·'PP'·교체 이름을 생략합니다.
- 룰에 따라 성능이 다른 특성은 배틀 동작과 설명이 함께 바뀝니다: 쇼다운의 8·7·6세대 모드에서 동작이 바뀐 특성 35종을 세대 순서대로 적용(예: 8세대 이하 불요의검·불굴의방패 매번, 변환자재·리베로 기술마다, 트랜지스터 1.5배, 배틀스위치 지우개굴닌자, 눈퍼뜨리기 싸라기눈 / 7세대 이하 정신력·둔감·마이페이스·배짱 위협 무효 없음, 탈 데미지 없음 / 6세대 질풍날개 HP 무관, 스킨 1.3배, 깨어진갑옷 스피드 +1, 부모유대 2번째 1/2, 짓궂은마음 악타입에게도). 무제한은 그중 강한 쪽, 챔피언스 사양은 치유의마음 50%·도주·보이지않는주먹.
- 날씨: 8세대 이하 룰은 눈 날씨가 싸라기눈(데미지), 9세대·챔피언스는 설경. 기술·날씨 이름도 '싸라기눈'·'설경'으로 따로(섞어 쓰지 않음). 챔피언스 사양에서 효과가 바뀐 기술(소금절이 1/16, 골드러시 특공 −2, 아이언헤드 풀죽음 20% 등)은 설명도 챔피언스 기준.
- 무제한 룰의 상태이상(마비 1/8·잠듦·얼음)·날씨·필드는 챔피언스 방식.
- 연승·랭크 기록과 진행 중인 도전은 배틀 규칙마다 따로 저장(기록 화면에서 규칙별로 봄). 치트 팀은 같은 포켓몬을 여러 마리 넣을 수 있음.
- 배틀타워·팩토리의 미진화체는 쉬움 난이도에서만 나옵니다(보통 타워의 초반 6회전은 약한 최종 진화, 보통 팩토리는 브론즈 등급부터). 성능이 좋은 미진화체(종족값 합계 450 이상 — 폴리곤2·미끄네일·럭키·스라크 등, 진화의휘석으로 자주 쓰이는 글라이거·쌍검킬·포푸니 등)는 난이도와 관계없이 최종 진화와 함께 나옵니다.
- **휴대폰 가로 화면**(앱도 자동 회전을 따름): 하이브리드 배치 — 왼쪽에 큰 필드(16:9)와 그 아래 대화창(챔피언스식), 오른쪽 한 칸에 기믹·기술(한 줄에 하나)·[포켓몬·기권·기록] 버튼(교체는 포켓몬 버튼으로 오른쪽 칸 전체에 크게)·기술 2×2(타입 색 큰 버튼, 상성은 버튼 위 작은 띠)·교체 6칸·기권/기록을 함께(쇼다운식). 타이틀·메뉴는 가로 그림.
- **PC**: 같은 웹 빌드(`dist/index.html`, PWA)를 PC 브라우저에서 열면 가로 화면 배치로 바뀝니다 — 왼쪽 큰 배틀 필드, 오른쪽 조작 패널. 키보드: 숫자 1~6 = 기술·교체·대상 고르기, Enter/Space = 싸운다·메시지 넘기기, Esc/Backspace = 뒤로·창 닫기. 웹에서 배틀 중에 탭을 닫거나 새로고침하면 브라우저의 '변경사항이 저장되지 않을 수 있습니다' 확인창이 뜹니다(리플레이·배틀이 끝난 뒤·안드로이드 앱 제외). 넓은 화면의 배틀은 쇼다운식 배치(왼쪽 위 필드, 아래에 메시지와 공격·교체를 함께, 오른쪽에 배틀 기록 — 턴마다 제목·자동 스크롤, 더블배틀은 대상 고르기(상대는 어두운 빨강·내 편은 남색 카드, 여러 대상 기술은 맞는 포켓몬끼리 노란 선으로 이어 보임)·'◀ 뒤로'로 앞 선택 취소, 필드 양옆에 트레이너 그림과 파티 현황(양옆 빈칸은 배틀 배경의 색을 어둡게 가져온 하늘·지평선·바닥 띠로 채움), 마우스를 올리면 포켓몬·기술 정보 상자 — 아래 교체 버튼 포함, 상대는 드러난 정보만. 마우스를 올려도 ▶ 커서는 안 나옴(키보드 이동 때만))이고, 타이틀·메뉴 배경은 가로용 그림(`arena_title_wide`), 메뉴 화면은 화면 높이에 맞춰 1.25~1.4배로 키웁니다.

## 규칙
- **기술 사양은 포켓몬 챔피언스 기준**(`src/ps/champions-moves.json`, Serebii ‘Updated Attacks’): 골드러시 명중 95·특공 2랭크 하락, 빙산바람 위력 120, 베어가르기 80, 임팩트 100, 메테오어설트 170,
  스냅트랩 강철타입, 성장 풀타입, 더블쇼크 필중·펀치, 소금절이 1/16(물·강철 1/8), 독실 스피드 2랭크 하락, 크로스클로·섀도클로·드래곤클로 베기 기술, 밀크드링크 아군 대상 등 32개.
  PP도 챔피언스 방식(PP업 없이 5→8, 10→12, 15→16, 20 이상→20)으로 맞췄습니다. Z기술·다이맥스 기술 위력은 바뀐 위력에서 공식 표대로 다시 계산됩니다(예: 빙산바람 120 → Z 190, 맥스 140). 시뮬레이터와 기술 설명 표시 양쪽에 적용됩니다.
- **Showdown 의 champions 모드도 함께 적용**: 위력·명중(블러드문 130, 트리플다이브 35, 하이퍼드릴 120, 앵커샷 90, 드래곤해머 100, 아가미물기·전격부리 80, 기어소서 60/90, 소울비트 필중 등), PP(방어 계열·희망사항·모래바람·설경 등), 프리즈드라이 얼음 효과 없음, 속이다·기습 등 첫 턴 제한, 앙코르·사슬묶기·저주·배수의진 동작.
  특성: 재생력·자연회복·치유의마음·보이지않는주먹·도주·분노의껍질·발끈·위기회피·도망태세. (기술 설명 화면의 위력·명중·PP 도 같은 값)
- **배울 수 있는 기술**: 모든 규칙에서 본가 전 세대 목록 + Showdown champions 모드의 기술 목록(포켓몬 챔피언스 기준, 예: 아쿠스타 아쿠아제트·아쿠아브레이크)을 합친 것. 로토무 폼처럼 폼 체인지하는 포켓몬은 원래 모습의 기술도 모두 배움.
- **상태이상도 포켓몬 챔피언스 기준**(Showdown 의 champions 모드와 같음): 마비로 못 움직일 확률 1/8(본가 1/4), 잠듦 2~3턴(2턴째에 깰 확률 1/3, 본가 1~3턴), 얼음 최대 3턴·매 턴 1/4 로 녹음(본가 1/5·상한 없음).
  화상 1/16·독 1/8·맹독 n/16·씨뿌리기 1/8 등 지속 데미지는 본가와 같음.
- **능력 포인트(포켓몬 챔피언스 방식)**: 노력치 대신 능력마다 0~32포인트, 합계 66포인트. 개체값은 없고 모두 최대. 레벨 50에서 1포인트 = 능력치 +1.

## 배틀 계산기
메인 메뉴의 배틀 계산기: 공격/방어 포켓몬(저장된 팀의 세트 또는 종족 검색 → 추천 세트, 세트 편집 가능)·기술·랭크·상태이상·테라스탈·날씨·필드·벽·급소·도우미를 넣으면

- 모의 랭크 매치(포켓몬 챔피언스 방식): 싱글 6→3 / 더블 6→4. 6마리를 등록하고 상대 엔트리를 본 뒤 참가 포켓몬을 고릅니다. 이기면 RP +25, 연승할수록 +29·+33·+37·최대 +41(마스터볼급부터 +5), 지면 −12(비기너는 0)·연승 초기화. 10연승 이상이면 가끔(20%) '상위 매칭'으로 480 RP 높은 실력의 상대가 나오고, 이기면 +25 보너스(지면 일반 매치처럼 연승이 끊김, v2.53.5). (v2.53 에서 획득 RP·연승 보너스는 낮추고 승급 기준은 1.2배로 올림 — 예전 RP 는 한 번 1.2배로 바꿔 등급 유지)
  등급: 비기너(0) → 몬스터볼급(120) → 슈퍼볼급(360) → 하이퍼볼급(720) → 마스터볼급(1200), 각 등급은 5 → 1 단계로 나뉩니다(예: 몬스터볼급 5 = 120, 몬스터볼급 1 = 312, 마스터볼급 1 = 1680~).
  마스터볼급부터 **가상 순위**가 나옵니다: 가상의 다른 트레이너들도 시즌(한 달) 동안 날마다 조금씩 올라가고 순위도 날마다 흔들려서, 가만히 있으면 순위가 내려갑니다. 100위 안에 들면 **챔피언급**(단계 없음, 대략 2,400 RP 안팎).
  RP가 오를수록 상대 AI 실력(0.5→0.97)과 종족값 하한(420→560)이 오르고 능력 포인트도 꽉 채우며, 360 RP 부터 준전설, 전설·환상이 허용된 룰에서는 720 RP 부터 전설 1마리·1200 RP 부터 2마리가 나옵니다. 마스터볼급에서는 가끔 챔피언·주인공·악의 조직 보스가 강적으로 등장하고(챔피언급은 더 자주), 상대 트레이너군도 등급에 맞춰 슈퍼볼급부터 어린이 트레이너가 빠지고 마스터볼급부터는 엘리트·베테랑 트레이너 같은 실력자만 나옵니다. 일반 트레이너 이름은 남녀 각 120개.
  배틀 도중 앱을 끄거나 새로고침해도 패배를 피할 수 없습니다(v2.53.4): 시작 때 '지면 이렇게 됨'을 저장해 두고, 결과 없이 남아 있으면 다음에 앱을 열 때 패배로 처리하고 랭크 매치 화면에서 알려 줍니다.

## 빌드
- 기본 빌드는 저용량판(그림·울음소리·애니메이션 미포함). 애니메이션은 jsDelivr(저장소의 public/anims, 마지막 변경 커밋 고정)에서, 오프라인 묶음은 `offline/*.zip`(`scripts/make-offline-zips.py`, 현재 브랜치의 raw.githubusercontent.com 주소)에서 받음.
- `node battle-kr/build.mjs --full --android` 로 만들면 그림 등이 앱에 포함된 묶음판(약 30MB)이 됩니다.
- **오프라인 그림**: `bash battle-kr/scripts/fetch-sprites.sh` 로 포켓몬(정지 그림 앞/뒤·색이 다른 모습, 약 1,300종 × 4), 트레이너, 대타 인형, 도구 아이콘을
  `public/sprites/` 에 받아 두면 빌드할 때 앱에 들어갑니다(약 22MB, 저장소에는 올리지 않음). 인터넷이 되면 움직이는 그림을, 안 되면 앱 안의 그림을 씁니다.
```
npm ci --omit=optional          # 저장소 루트
node build                      # dist/ (시뮬레이터 컴파일)
node battle-kr/scripts/gen-data.cjs   # 한글 데이터 → src/gen/dex.json
node battle-kr/build.mjs        # → battle-kr/dist/index.html (한 파일, 약 4.5MB)
node battle-kr/build.mjs --android && cd battle-kr/android && ./gradlew assembleRelease
```
- 안드로이드 SDK 경로는 `android/local.properties` 의 `sdk.dir`.
- 서명: 환경변수 `BATTLESIM_KEYSTORE`(키스토어 경로, 별칭 `battlesim`)·`BATTLESIM_KEY_PASSWORD` 를 주면 그 키로, 없으면 디버그 키로 서명합니다. 키는 저장소에 넣지 마세요 (같은 키로 서명해야 업데이트 설치 가능).
- GitHub Actions `배틀 시뮬레이터 APK` 워크플로가 APK·웹 파일을 아티팩트로 만듭니다.
- AI 자체 대전 테스트: `node battle-kr/build.mjs --test` → `test/selfplay.html` 을 열고 `selfplay(25, 9, false, 0.95, 0.3)` (기믹 사용 횟수도 표시).
